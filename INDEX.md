## 🚀 Getting Started

### Step 1: Clone or Download
```bash
cd /path/to/recruitment-dashboard
```

### Step 2: Read Quick Start
```bash
# Open and read:
cat QUICKSTART.md
```

### Step 3: Install & Run
```bash
pip install fastapi uvicorn pandas openpyxl
uvicorn app:app --reload --port 8000
# Open: http://127.0.0.1:8000
```

### Step 4: Import Sample Data
1. Click "Import Data"
2. Select `recruitment_base_template.xlsx`
3. Click "Import"

### Step 5: Explore Features
- Search candidates
- Sort and filter
- Generate reports
- Match candidates
- Update statuses
